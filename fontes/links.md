# 📚 Curadoria de Fontes e Referências Técnicas

Este arquivo centraliza as fontes oficiais, artigos científicos, documentações e guias recomendados para aprofundamento em IA Generativa, Large Language Models (LLMs) e Engenharia de Software auxiliada por IA.

---

## 📄 Base Científica e Papers

### 1. Attention Is All You Need (Vaswani et al., 2017)
*   **Descrição:** O paper científico revolucionário que introduziu a arquitetura *Transformer* e o mecanismo de *Self-Attention*, servindo como base técnica para todos os LLMs modernos (como a família GPT, Claude, LLaMA, Gemini, etc.).
*   **Link Oficial (arXiv):** [arXiv:1706.03762](https://arxiv.org/abs/1706.03762)
*   **Cópia Local:** [attention_is_all_you_need.pdf](./attention_is_all_you_need.pdf)

### 2. ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)
*   **Descrição:** Paper fundamental que introduziu o padrão ReAct, descrevendo como instruir LLMs a alternar entre "pensar" (geração de raciocínio) e "agir" (chamar ferramentas/APIs externas) para resolver tarefas complexas.
*   **Link Oficial (arXiv):** [arXiv:2210.03629](https://arxiv.org/abs/2210.03629)

## 🛠️ Documentações de Plataformas e Ferramentas

### 3. OpenAI Documentation
*   **Descrição:** Guia de referência para a API da OpenAI. Excelente para entender parâmetros de chamadas (temperatura, penalties), melhores práticas de prompts e recursos como Function Calling e Structured Outputs.
*   **Link:** [OpenAI Docs](https://platform.openai.com/docs)
*   **Cookbook:** [OpenAI Cookbook](https://cookbook.openai.com) (Exemplos práticos de código e implementação).

### 4. Anthropic Claude Documentation
*   **Descrição:** Documentação oficial para a família de modelos Claude. Destaca-se pelas melhores práticas de Prompt Engineering para modelos avançados e exemplos de uso do System Prompt.
*   **Link:** [Anthropic Docs](https://docs.anthropic.com)

### 5. Hugging Face Course & Hub
*   **Descrição:** Comunidade e plataforma líder em modelos Open Source. O Hugging Face Course ensina sobre Transformers, Tokenização e como utilizar modelos localmente com a biblioteca `transformers` do Python.
*   **Link:** [Hugging Face Course](https://huggingface.co/learn/nlp-course)

### 6. GitHub Copilot
*   **Descrição:** Documentação e guias de uso do assistente de código inteligente do GitHub integrado à IDE.
*   **Link:** [GitHub Copilot Features](https://github.com/features/copilot)

## 💡 Guias de Prompting e Desenvolvimento

### 7. Prompting Guide (DAIR.AI)
*   **Descrição:** O maior e mais completo guia de Engenharia de Prompts open-source do mundo. Contém explicações sobre técnicas como Zero-shot, Few-shot, Chain-of-Thought (CoT), Prompt Tuning e segurança de prompts.
*   **Link:** [PromptingGuide.ai](https://www.promptingguide.ai/pt) (Versão em Português disponível).

### 8. Papers with Code
*   **Descrição:** Recurso incrível para encontrar papers científicos categorizados por tarefas de Machine Learning, acompanhados de suas respectivas implementações de código aberto no GitHub.
*   **Link:** [Papers with Code](https://paperswithcode.com)
